# Posts

One folder per reel, named `post-NN-slug`, where `NN` is the post's **ID in the Content Plan tab** of `Unpack_and_Explain_Tracker.xlsx` (zero-padded) and `slug` is a short topic word. The same name is used everywhere:

| Where | Example |
|---|---|
| Tracker | Content Plan ID `2`, Scripts tab "Post 2" |
| Approved script | `posts/post-02-gps/script.md` |
| Video code | `video/src/posts/post-02-gps/` |
| Voice-over + captions | `video/public/posts/post-02-gps/` |
| Studio composition | `Post02-Gps` |
| Renders | `video/out/post-02-gps.master.mp4` |

`script.md` starts with a header that links back to the tracker row, then the script table, the facts to verify, and the caption.
