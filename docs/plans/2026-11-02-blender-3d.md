# Blender 3D Implementation Plan

> Executed inline in the main session (CLAUDE.md: no subagents). Steps use checkboxes.

**Goal:** Every new reel gets Blender-rendered 3D (lit line art) on frame 0, the hook, the mechanism and a cover still, from a catalog of real models, synced to the VO.

**Architecture:** A pure TS job builder (`src/templates/blenderJob.ts`) turns `script.blender` + `vo.json` into frame-exact clip specs and a hash. `scripts/blender.ts` writes the job and runs headless Blender (`blender/*.py`) which renders RGBA PNG sequences + `labels.json` + `manifest.json` into `public/posts/<id>/3d/`. Remotion plays them with `BlenderClip`, draws labels in 2D, and throws when the manifest hash is stale.

**Tech stack:** Blender 4.5 LTS (Eevee, Freestyle, compositor Glare), Python bpy, `@gltf-transform/*` + `meshoptimizer` for model intake, Remotion 4.0.539, vitest.

Spec: `docs/specs/2026-11-02-blender-3d-design.md`.
