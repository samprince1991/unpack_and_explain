# Ideas README redesign

Date: 2026-10-30. Status: approved.

## Goal

`ideas/README.md` (generated by `npm run tracker`) should first answer "what topics do we have?", so new ideas go under an existing theme instead of repeating one. It should be easy to read and show more per idea (hook, source, open facts).

## Decisions

- **Fixed taxonomy** in `ideas/categories.yml` (category → list of sub-categories). Each `idea.md` has `category` + `subcategory` (replacing `area`). The tracker errors on an unknown category or a sub-category not listed under its category.
- **Carousels removed**: their idea folders are deleted, `Carousel` is no longer a format, IDs are numbers only.
- `week` stays (Schedule); `notes` stays in files but is not shown.

Initial taxonomy:

| Category | Sub-categories |
|---|---|
| Everyday tech | Location & GPS, Wireless, Internet, Data & codes |
| Money & payments | Payments, Markets, Credit |
| Aviation & engineering | Flight, Engines, Structures, Space |

## README layout

1. **Header**: what the folder is, plus an at-a-glance line (idea count, count per status, next unposted idea by date).
2. **Topics**: one `##` per category (in `categories.yml` order) with its count; one table: Sub-category | # | Idea | Hook | Fmt | Status | Source | To verify. Rows sorted by sub-category (taxonomy order), then date. Status links to the live post when `link` is set. "To verify" = number of `verify` items (`-` when none). Below the table: `No ideas yet: ...` for empty sub-categories.
3. **Schedule**: all ideas by date: Date | Wk | # | Idea | Category › Sub-category | Fmt | Status | Words | Est. s.
4. **Performance**: posted ideas with watch link and metrics.
5. **Formats**: E / F / Q comparison and best-format line (needs 3 posted per format).
6. **How to**: add an idea, after posting, add a sub-category; idea → post naming table.
7. **Legend**: formats, statuses, metric formulas, schedule note.

## Code

- `video/scripts/lib/tracker.ts`: `Taxonomy` type, `parseTaxonomy`, `validateIdea(idea, taxonomy)`, one render function per README section, no carousel handling.
- `video/scripts/tracker.ts`: reads `ideas/categories.yml`.
- `video/scripts/lib/tracker.test.ts`: taxonomy validation, empty sub-category line, catalog row, numeric IDs only.
